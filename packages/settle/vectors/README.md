# Settlement vectors

Generated by `pnpm vectors` (`scripts/gen-vectors.ts` → `scripts/vectors.ts`, fixed seed `0x5e771e`). Do not edit by hand. Regenerating must not change them; `test/vectors.test.ts` fails if the committed files differ from a fresh generation.

Conventions (P1.1): JSON, UTF-8, 2-space indent, trailing newline. **Every numeric field is a decimal string** (Foundry: `vm.parseUint(vm.parseJsonString(json, key))`). Addresses and hashes are lowercase `0x` hex. Each file's `vectors` array is sorted by `id`.

## `stakes-closed-form.json`

Consumers: the `FlockedEscrow` Foundry tests (W1-B/D), TypeScript.

```json
{ "formulaVersion": "1", "kind": "stakes-closed-form",
  "vectors": [ { "id", "stake", "feeBps", "creatorBps", "capMultiple", "minEntrants", "n0", "n1", "nVoid",
                 "expected": { "status", "refundReason", "winner", "lossPool", "fee", "creatorFee", "distributable",
                               "w", "rebatePool", "r", "dust", "winPayout", "rebatePayout", "voidRefund", "roundBalance" } } ] }
```

- `status`: `"2"` SettleProposed, `"3"` RefundProposed. `refundReason`: `"0"` for a settlement, else `"1"`–`"3"`. `winner`: `"0"`, `"1"`, or `"255"` for a refund.
- For a refund every money field except `voidRefund` and `roundBalance` is `"0"`.
- `winPayout = stake + w`, `rebatePayout = r`, `voidRefund = stake`, `roundBalance = (n0 + n1 + nVoid) · stake`.
- 63 vectors: every refund reason, ties, cap binding and not (incl. the ratio-10/11 boundary), r = 0 and r > 0, nVoid = 0 and > 0, stake 1 and 100 USDC, fees 0/0 and summing to 10000, capMultiple 1 and 10, `minEntrants` − 1 and exact, ≥ 100,000 per side, headcounts in the billions, and 24 seeded random cases. Every vector with ≤ 300,000 entries is cross-checked against the general formula entry by entry at generation time.

## `stakes-payout-merkle.json`

```json
{ "kind": "stakes-payout-merkle",
  "vectors": [ { "id", "chainRoundId", "leaves": [ { "account", "kind" } ], "root",
                 "proofs": [ { "account", "kind", "proof": ["0x…"] } ] } ] }
```

Leaf: OpenZeppelin StandardMerkleTree `["uint256","address","uint8"]` = (chainRoundId, account, kind); kind 0 = Win, 1 = Rebate, 2 = VoidRefund. `leaves` are sorted by account, then kind. Trees: 1 leaf (empty proof), 2 leaves, 7 leaves, 25 leaves, and 1,203 leaves (a capped 100 vs 1,100 round with 3 VOIDs; 32 sampled proofs including the first and last leaf; `chainRoundId` above 2^128). Leaves of the larger trees come from real settled rounds, so each account has exactly one leaf.

## `free-general.json`

Consumers: TypeScript only (verify CLI, watcher).

```json
{ "formulaVersion": "1", "kind": "free-general",
  "vectors": [ {
    "id", "roundId": "0x<16 bytes>",
    "params": { "feeBps", "creatorBps", "capMultiple", "minEntrants", "creatorAwardBps", "countQualifyingOnly": false },
    "entries": [ { "account": "0x<userIdHash>", "stake", "option": "0" | "1" | null, "voidReason": null | "<VOID_REASONS>", "qualifies"?: true } ],
    "expected": {
      "record": { "outcome": "settled" | "refunded", "refundReason": null | "1" | "2" | "3", "n": ["", ""], "w": ["", ""],
                  "winner": null | "0" | "1", "lossPool", "fee", "creatorFee", "distributable", "rebatePool", "dust",
                  "voidCount", "voidStake", "total", "creatorAward" },
      "payouts": [ { "account", "kind": "win" | "rebate" | "void_refund" | "refund", "amount" } ],
      "payoutRoot": "0x…" | null
    } } ] }
```

- `account` is `userIdHash(roundId, userId)` for a deterministic `userId`; entries are sorted by account.
- `payouts` are exactly `settle()`'s output (sorted by account, then kind; zero rebates omitted). `payoutRoot` is `freePayoutTree(roundId, payouts)` with leaves (bytes16 roundId, bytes32 userIdHash, uint256 amount), or `null` when there are no payouts.
- `countQualifyingOnly` and `qualifies` are JSON booleans; `option` and `refundReason` are strings or `null`.
- 29 vectors: SET-3 minority-holds-more-stake, uneven-stake cap binding, every VOID reason, refunds 1–3 (incl. empty and VOID-only rounds), room qualification both ways, single-unit and 10^30 stakes, a general round with fees, and 16 seeded random rounds.
