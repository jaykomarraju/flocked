## Spec issues

1. **Account merge / Notifications:** merge does not move `push_subscriptions` or `notification_prefs`; recommend per-channel merge/upsert semantics onto the surviving account.
2. **Guardian void / Notifications:** a pre-close guardian void can consume the day's `outcome` dedupe key and suppress the later Free result; recommend using the `refunded` key for that pre-beacon notification.
3. **Gas and UX / daily cap:** “per user per day” is implemented as smart-wallet sender and UTC day because the endpoint is unauthenticated. Specify the identity and timezone explicitly.
4. **Watcher defaults:** missing attestation RPC or an empty `COUNTRY_ALLOW` yields `unable` and pages. Confirm that fail-closed launch behavior and the paid-Workers requirement.
5. **Share cards:** `/rounds/:id/card` has no mode parameter; cache purge remains colo-local and room sharing remains daily-only. Specify the selected mode, stale-copy tolerance and room privacy policy.
