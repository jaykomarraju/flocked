# Wave 1: Foundations

**Goal.** A pnpm workspace with CI, the `FlockedEscrow` contract with its full Foundry test suite, and the pure settlement package `@flocked/settle` with property tests and recorded vectors. The contract's closed form is proven equal to `@flocked/settle` through those shared vectors.

**Base.** Tag `wave-0` (the PLAN-0 commit on `main`). There is no earlier Z, so `docs/sessions/W0-Z.md` doesn't exist; prompts point at this file instead.

**Why this split.** The three parallel sessions own disjoint roots: A the workspace root and `packages/shared`, B `contracts/`, C `packages/settle`. B and C can't use A's root, so each is self-contained in wave 1 and D folds them in.

## Pinned interfaces

### P1.1 Settlement vectors (C produces, B consumes a seed copy, D connects)

All files are JSON, UTF-8, 2-space indented, with a trailing newline. **Every numeric field is a decimal string**, so `bigint` round-trips and Foundry reads it with `vm.parseUint(vm.parseJsonString(json, key))`. Addresses are lowercase `0x` hex. Arrays keep a stable order (by `id`).

`packages/settle/vectors/stakes-closed-form.json`:

```json
{
  "formulaVersion": "1",
  "kind": "stakes-closed-form",
  "vectors": [
    {
      "id": "settle-basic",
      "stake": "5000000",
      "feeBps": "500",
      "creatorBps": "100",
      "capMultiple": "10",
      "minEntrants": "20",
      "n0": "30",
      "n1": "12",
      "nVoid": "1",
      "expected": {
        "status": "2",
        "refundReason": "0",
        "winner": "1",
        "lossPool": "…", "fee": "…", "creatorFee": "…", "distributable": "…",
        "w": "…", "rebatePool": "…", "r": "…", "dust": "…",
        "winPayout": "…", "rebatePayout": "…", "voidRefund": "…",
        "roundBalance": "…"
      }
    }
  ]
}
```

- `status` uses the contract's `Status` enum values: 2 = SettleProposed, 3 = RefundProposed.
- `refundReason` is 0 for a settlement, otherwise 1, 2 or 3. `winner` is 0 or 1, or `"255"` for a refund. For a refund, every money field except `voidRefund` and `roundBalance` is `"0"`.
- `winPayout` = s + w, `rebatePayout` = r, `voidRefund` = s, and `roundBalance` = (n0 + n1 + nVoid)·s.
- Coverage: at least 40 vectors. Include every refund reason; a tie; the cap binding and not binding; r = 0 and r > 0; nVoid = 0 and > 0; stake 1 (base unit) and stake 100 USDC; minimum and maximum fees; capMultiple 1 and 10; `minEntrants` boundary (n0 + n1 = minEntrants − 1 and = minEntrants); and large headcounts (≥ 100,000 per side).

`packages/settle/vectors/stakes-payout-merkle.json`:

```json
{
  "kind": "stakes-payout-merkle",
  "vectors": [
    {
      "id": "small",
      "chainRoundId": "7",
      "leaves": [ { "account": "0x…", "kind": "0" } ],
      "root": "0x…",
      "proofs": [ { "account": "0x…", "kind": "0", "proof": ["0x…"] } ]
    }
  ]
}
```

The leaf is OpenZeppelin StandardMerkleTree `["uint256","address","uint8"]` = (chainRoundId, account, kind), where kind is 0 = Win, 1 = Rebate, 2 = VoidRefund. Include at least a 1-leaf, a 2-leaf, an odd-count and a ≥ 1,000-leaf tree (proofs for a sample of leaves).

`packages/settle/vectors/free-general.json`: general-formula vectors (entries with stakes, options and validity in; per-entry payouts and the settlement record out). TypeScript consumers only (verify, watcher). The shape is C's choice, documented in `packages/settle/vectors/README.md`.

Vectors are generated by `pnpm --filter @flocked/settle vectors` (a deterministic script with a fixed seed), and committed. From W1-D on, CI fails if regenerating changes them.

### P1.2 `@flocked/settle` public API (C)

```ts
export const FORMULA_VERSION = 1;
export type OptionIndex = 0 | 1;
export type Mode = 'free' | 'stakes';
export const VOID_REASONS = ['decrypt_failed', 'non_canonical_header', 'wrong_target', 'bad_plaintext',
  'bad_option', 'not_anchored', 'stake_out_of_range'] as const;
export type VoidReason = (typeof VOID_REASONS)[number];
export type RefundReason = 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8;          // spec codes; settle itself decides only 1–3

export interface SettleParams {
  feeBps: number; creatorBps: number; capMultiple: number; minEntrants: number;
  creatorAwardBps?: number;            // Free only; default 0
  countQualifyingOnly?: boolean;       // room rounds: minEntrants counts only entries with qualifies = true
}
export interface EntryInput {
  account: string;                     // Stakes: lowercase address. Free: hex userIdHash (bytes32)
  stake: bigint;
  option: OptionIndex | null;          // null when VOID
  voidReason: VoidReason | null;       // null when valid
  qualifies?: boolean;                 // room-minimum qualification
}
export interface SettlementRecord {
  outcome: 'settled' | 'refunded'; refundReason: 1 | 2 | 3 | null;
  n: [bigint, bigint]; w: [bigint, bigint]; winner: OptionIndex | null;
  lossPool: bigint; fee: bigint; creatorFee: bigint; distributable: bigint;
  rebatePool: bigint; dust: bigint; voidCount: bigint; voidStake: bigint; total: bigint;
  creatorAward: bigint;                // Free only, outside the invariant
}
export interface Payout { account: string; kind: 'win' | 'rebate' | 'void_refund' | 'refund'; amount: bigint; }
export function settle(entries: readonly EntryInput[], params: SettleParams): { record: SettlementRecord; payouts: Payout[] };   // payouts sorted by account, then kind
export function settleStakesClosedForm(i: { stake: bigint; n0: bigint; n1: bigint; nVoid: bigint } & SettleParams): StakesClosedForm;
export function checkInvariant(record: SettlementRecord, payouts: readonly Payout[]): void;   // throws on violation
// Merkle (OpenZeppelin StandardMerkleTree)
export function stakesPayoutTree(chainRoundId: bigint, leaves: { account: `0x${string}`; kind: 0 | 1 | 2 }[]): { root: `0x${string}`; proof(account, kind): `0x${string}`[] };
export function freePayoutTree(roundId: Uint8Array /*16*/, leaves: { userIdHash: `0x${string}`; amount: bigint }[]): …;
export function freeCommitmentTree(leaves: FreeCommitmentLeaf[]): …;   // (bytes16 roundId, uint8 mode, bytes32 userIdHash, uint64 stake, bytes32 commitment, uint32 seq)
export function userIdHash(roundId: Uint8Array, userId: Uint8Array): `0x${string}`;  // keccak256(abi.encode(bytes16, bytes16))
```

- No JavaScript `number` for money anywhere. `number` is allowed only for bps, cap and counts in params.
- Dependencies limited to `@openzeppelin/merkle-tree` and `viem` (for keccak and ABI encoding). No Workers or Node APIs, so it runs in the browser, Workers and Node.
- Refunded results return `refund` payouts of every stake (valid and VOID).

### P1.3 `FlockedEscrow` (B)

The interface is exactly the spec's `IFlockedEscrow`. Additionally pinned (W2-B, W6-B and W6-A depend on these):

- File `contracts/src/FlockedEscrow.sol`; closed-form math in `contracts/src/lib/StakesMath.sol` (a pure library mirroring P1.2's `settleStakesClosedForm`).
- Constructor: `constructor(IERC20 usdc, address admin, address guardian, address operator, address pauser, address ticketSigner, address treasury, uint64 drandGenesis, uint64 drandPeriod)`.
- EIP-712: OpenZeppelin `EIP712("Flocked", "1")`, so the chain ID is `block.chainid` (Decision log, Oct 7, 2026). Typehash `EntryTicket(uint256 roundId,address wallet,bytes32 personTag,uint64 expiry)`. Signature checked with `ECDSA.recover` (65-byte signatures).
- Enum values: `Status { None=0, Open=1, SettleProposed=2, RefundProposed=3, Settled=4, Refunded=5 }`, `Kind { Win=0, Rebate=1, VoidRefund=2 }`. Refund reasons as uint8 codes 1–6 (spec table).
- Claim leaf: `keccak256(bytes.concat(keccak256(abi.encode(roundId, account, uint8(kind)))))`.
- Views needed off-chain (names pinned): `rounds(uint256) → (RoundConfig cfg, Status status, uint32 entryCount, uint128 roundBalance, …)` via a `getRound(uint256)` returning a struct; `beaconTime(uint64)`; `ticketSigner()`; `treasury()`; `hasEntered(uint256,address)`; `personTagUsed(uint256,bytes32)`; `withdrawable(address)`; `roundCount()`.
- Timelocks are built in, not via a separate TimelockController: `schedule*`/`execute*`/`cancel*` per change, with events. 72 h for ticket signer, treasury, `OPERATOR_ROLE` grants and rescue; 7 days for guardian replacement. Revocation, `setTicketSigner(address(0))` and pause are immediate.
- Custom errors (no revert strings). NatSpec on every external function.
- USDC in tests: a `MockUSDC` (6 decimals, EIP-2612 permit) in `contracts/test/mocks/`.
- **As built (W1-B, confirmed by W1-Z).** All of the above, plus additive extras: views `hasClaimed`, `totalObligations`, `timelockReadyAt`, `operationId`, `ticketDigest`, `domainSeparator`; events `Credited`, `Withdrawn`, `Timelock{Scheduled,Executed,Cancelled}`, `TicketSignerSet`, `TreasurySet`, `GuardianReplaced`, `Rescued`. `beaconTime` returns `uint256`.
- **Amended by W1-Z owner decisions (Oct 7, 2026; built in W2-B):** `unpause` is `DEFAULT_ADMIN_ROLE` only (pause stays `PAUSER_ROLE`). `GUARDIAN_ROLE` always has exactly one holder: `transferGuardian(address newGuardian)` (guardian, immediate) hands it on, `grantRole`/`revokeRole`/`renounceRole` revert for it, a `guardian()` view returns the holder, and `executeGuardianReplacement` is a single write. No `withdrawTo`.

### P1.4 Workspace conventions B and C follow before A's root exists
